How It Works

Simple by design.
Powerful by function.

No training needed. Both admins and interns are productive from minute one.

01
🔑

Sign In Instantly

Each intern and admin has a pre-set, hashed login. Open the app, enter credentials, and you're inside your personal dashboard in seconds — no setup required.

02
📋

Tasks Get Assigned

Admin creates tasks — single or bulk to all 11 interns at once. Tasks appear on each intern's Kanban board sorted by Office, Academic, or Personal category.

03
🏆

Complete & Earn Points

Interns tick off tasks, submit daily entries with contributor codes, and watch their score grow. Every action is verified before points are credited — no shortcuts.

Verification System

Contributor Code Verification

Third-party contributors hold secret codes. Interns enter the code to prove attendance or task completion. No code — no points. Zero exceptions.

✓
Category-specific contributors — one per entry type, or a single one for all categories.
✓
Task-approval-only mode — contributors can be restricted to verifying task completions only.
✓
Codes never shown to interns — admin manages them in a hash-locked Settings panel.
✓
Send Request fallback — interns escalate to admin approval if contributor is unavailable.

User Guide

Everything you need to
get started fast

New to TraineeXP? These four sections walk through everything the app does — step by step.

01
🗺️

Introducing the Features

TraineeXP shows exactly what it can do from the moment you sign in. Every major feature is immediately visible on the dashboard.

  • Points dashboard with live score and obedience %
  • Kanban board with today's assigned tasks
  • Entry submission with contributor verification
  • Real-time notifications and task alerts
02
🧭

Guiding Users Through the App

Every button, flow, and action is clearly labelled. Interns and admins are guided through each workflow intuitively — no manual required.

  • Sidebar navigation with role-based menu items
  • Color-coded status badges: Done, Pending, Approval Required
  • Empty states explain what to do next when nothing is there
  • Contextual labels on every button and action
03
🔐

Collecting Information Securely

TraineeXP collects only what it needs — securely. Passwords are SHA-256 hashed, contributor codes are hidden from interns, and all data syncs through Firebase.

  • Passwords stored as SHA-256 hashes — never as plaintext
  • Contributor code required before any entry is counted
  • Settings panel protected by a separate hash-verified lock
  • Session persistence — stay logged in between sessions
04
📈

Improving Retention & Performance

Interns who understand the system from day one perform better. The gamified points system and live scores keep everyone engaged and motivated.

  • Points and obedience score update in real-time after every action
  • Notifications remind interns of pending tasks and approvals
  • Recurring tasks ensure daily habits are consistently tracked
  • Excel export lets admins share progress with management
